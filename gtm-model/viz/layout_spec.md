# GTM Dashboard - Visual layout spec

Owner: Viz Designer. Canvas 1280 x 720 (16:9), page view 'Fit to page'. Theme: /workspace/corporate-theme/CorporateGreen.json (Arial 10, black text, 0 padding, column headers white on #006341). Coordinates are Format > General > Properties (x, y, width, height) in pixels. Backgrounds: viz/backgrounds/ (Canvas background > Image, Fit = Fit, transparency 0%). Mockups (EXAMPLE DATA): viz/mockups/. Generated by viz/build_viz.py - edit the script and re-run to change positions; the spec, backgrounds and mockups stay in sync.

Names below are only those in dax/measures.dax and the MPO / Dim_Date / Product queries. Anything not yet available is listed under Gaps.

## Shared rules
- Partial month (N1/N2/N8, measures.dax folder 9): Dim_Date-filtered pages carry a subtitle card [Partial Month Label] (amber #C98A1A via fx on [Is Partial Month] = 1) and month columns use a colour fx rule: [Is Partial Month] = 1 -> light #D5E5DC. Business Unit uses [Anchor Partial Month Label] / [Anchor Data Through Date] / [Anchor Is Partial Month] instead. Measures live in _mymeasures; date table Dim_Date.
- Header band 0-56 px (green) with page title + subtitle baked into the background; lime rule at 56-59. Slicer strip y 64-104. Content area y 116-712, 16 px margins, 8 px gutters.
- Month axes: Dim_Date[YEAR_MONTH_KEY] (categorical, sorted ascending); display MONTH_SHORT_NAME via a hierarchy YEAR > MONTH_NAME if preferred. All dates are the planned date unless the measure says (Exec Date).
- Colours: Executed #006341, Not Executed #9AA5AB, Planned #C8D1D6, Sales/with sales #7AB800, PY lines grey #5E6A71 dashed. Positive variance #006341, negative #B03A2E (no #00A651).
- Every visual: title on, Arial 10 black, padding 0, border off (background panels supply the frame), tooltips default + report tooltip pages where noted.
- Info button (top-right, 1224,12,40,32) on every page navigates to Glossary. Reset button (1224,64,40,40) applies bookmark 'BM Reset - <page>' (Data only, current page).
- Slicers: dropdown, single-select off, 'Select all' on, Apply button on (DirectQuery).
